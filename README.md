# 🏦 Bank Management System (C++)

A simple console-based **Bank Management System** written in **C++**.  
This project demonstrates basic Object-Oriented Programming concepts like **classes**, **objects**, **inheritance**, and **file organization using header and implementation files**.

---

## 📦 Features

- Create new bank accounts
- Deposit and withdraw money
- Display account details
- Show all account summaries
- Clean multi-file C++ project structure
- Makefile for easy compilation and management

---

## 📚 Concepts Used

- **Classes and Objects**
- **Encapsulation**
- **Header files (`.h`)**
- **Source files (`.cpp`)**
- **Makefile for build automation**
- **Console I/O operations**

---

## 🚀 How to Run the Project

### 📥 Install Dependencies
- Install **MinGW** (Windows)
- Add `C:\MinGW\bin` to your system's PATH

> Confirm `g++` and `mingw32-make` are installed:
```bash
g++ --version
